ArthSaathi Architecture

One adaptive engine · 7-agent society · Education-not-advice · Agentic RAG · Eval-gated · LangGraph

Diagram Brief

  • • User channels feed into Saathi, a LangGraph orchestrator that detects intent, language, literacy, and accessibility needs.
  • • Saathi routes each request to specialist agents for education, fraud protection, scheme guidance, cash-flow learning, accessibility, and nudges.
  • • The knowledge layer combines offline ingestion, hybrid retrieval, reranking, cited generation, scheme graph lookup, and multilingual voice services.
  • • Guardrails enforce education-not-advice, grounded citations, PII redaction, safe refusal, and human escalation where confidence or risk requires it.
  • • The evaluation harness validates chunking, embeddings, retrieval, generation, routing, and agent behavior before demo or deployment.
